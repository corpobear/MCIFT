# MCIFT 0.1.0a1

MCIFT 0.1.0a1 is an experimental public research alpha for deterministic multichannel
anomaly detection and condition monitoring. It is CPU-first, offline and NumPy-only at
runtime.

This alpha includes the deterministic exchange core, versioned telemetry and
vibration profiles, caller-owned chronological history, structured evidence, the
opt-in six-gate IMS profile, conventional centred RMS/excess-kurtosis/crest-factor
features and schema-4 serialization. CI covers Python 3.11-3.13 on Linux, Windows and
macOS, including NumPy 1.26 minimum compatibility, installed wheel/sdist smoke tests,
static analysis and dependency auditing.

An initial frozen NASA IMS Test Set 2 case study is documented with immutable source
commits. The run produced warning behavior before the terminal recording and no strong
warnings in the tested disrupted controls. It did not correctly localize the
documented failed bearing. That failure is part of the result, not an omitted edge
case.

This release does not establish physical theory, causal localization, production
reliability, safety, generalization or superiority over established methods. Exathlon
execution remains pending. NASA data are not included.

See `docs/ims-set2-case-study.md`, `docs/claims-and-limitations.md` and
`REPRODUCIBILITY.md` before using or citing results.
